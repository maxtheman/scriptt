Empty for now: the hook's code arrives here.

- which Claude Code events it handles (for example `UserPromptSubmit`, `PreToolUse`, `Stop`);

- how to install it: the `hooks` entry to add to `~/.claude/settings.json`;
- how to test it: a recorded event fed on stdin, and the output it must give.
