scriptt shows you how Claude Code understood your message before it starts work, and sends Claude back when it skips a step. In one week of my own work, 37% of my messages to Claude were corrections. 23 times Claude reported a task as done after doing a different step than the one I asked for.

scriptt keeps a record of what you and Claude both believe about your project, in a short file called world.py. It lists the things you work on and the requests you make. For each request it says what the request takes and what it gives back. It knows the difference between one thing, a list of things, and a thing that exists only after a request is done. So Claude cannot report the redesigned page as tested before the redesign exists.

When you send a message, a small model on your machine compares it with the record before Claude reads it. Each request becomes a call with its inputs. Words that match nothing in the record go to Claude as questions to ask you. Drag a different type onto any word or a different input into any call. scriptt saves the change and applies it every time the message is read again. When Claude stops, scriptt searches the transcript for a file written or a command run for each call. Claude goes back to finish the calls with neither.
