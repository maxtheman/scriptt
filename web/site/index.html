A harness for Claude Code in 2 files.

d1: a small decision model on your computer. d1 reads each message before Claude does. It decides which functions of your world the message demands. Drag to disagree with d1.

Install

      
curl -fsSL https://scriptt.ai/install.sh | sh

      
Needs Python 3.14. Run it in the folder of your project. It makes .scriptt/ with
        harness.py, world.py and SKILL.md. It adds 2 hooks and 1 skill to .claude/.
        python3.14 .scriptt/harness.py serve shows this page with your own events.

The world

      
world.py is the whitelist: classes, named things, and functions. A message can demand only
        a function that is listed here. The docstring of a function is the question that d1 answers with a yes or a no.
