scriptt

A hook for Claude Code. It reads each message into a typed template: the words that point at a thing, the words that ask for a thing, and the verbs that name a function.

The classes of the world

The session as a line map

One row per class, one column per message. A message that wants a class is joined to the reply that has it. Click a column to select that message. Left and right arrow keys also move.

The text as a typed template

Each slot is marked where it is in the text, with its class after it. A filled mark has a value. A dashed outline is a hole: the class is wanted and there is no value yet. A verb shows its function, with a line to each slot that can fill a parameter and to the class it wants.

The reads, one at a time

    
The hook asks the model one question for each class, again and again until the model
      finds no more. Words that were found are blanked before the next question.

Scratch editor for types

    
Drag a named thing onto a hole of its class to give it a value. Press and move over plain
      words to select them, then drag a class onto them to make a slot. Drag the class tag of a slot into a
      socket of a function. A drop that does not fit is refused, with the reason.
