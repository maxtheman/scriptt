scriptt

A harness for Claude Code in 2 files. Each message is a demand for computation. A small decision model, d1, decides which functions of your world the message demands. You drag to disagree.

curl -fsSL https://scriptt.ai/install.sh | sh     # needs Python 3.14. It makes .scriptt/ here: harness.py and world.py

The session

One row for each function of the world, one column for each event. A disc is a function that d1 says the message demands, larger when d1 is more sure. A line goes to the reply. The mark on the reply is filled when d1 says the reply does it. Click a column, or use the arrow keys.
