Make every solved problem AI intuition you own

Frontier models solve problems well, and they will keep doing so. scriptt is a harness that keeps you in the loop. It turns each solution into AI intuition. AI intuition is a fast answer from a small local model. You take it with you from one chat to the next.

works today

A to-do world

The code keeps 1 task and marks it done. A function gives the open tasks on a date.

todo.pyPython 3.14
from scriptt.world import Fact, Facts, Key, World


class Task(Fact):
    id: Key[str]
    title: str
    done: bool = False


todo = World.new(Task)
todo.add(Task(id="t2", title="Send the report"),
         source="me", true_from="2 Nov 2026")
todo.add(Task(id="t2", title="Send the report",
              done=True),
         source="me", true_from="3 Nov 2026",
         known="4 Nov 2026 10:00")


def open_tasks(view: World) -> Facts[Task]:
    return view.facts(Task).where(lambda t: not t.done)


print(open_tasks(todo.on("2 Nov 2026")))
print(open_tasks(todo.on("4 Nov 2026")))
output
id  title            done
t2  Send the report  no
(no items)

the goal

A stand-alone harness for programmers

Today, each AI starts each task from zero. It spends the same effort to solve a problem again, even when it solved that problem before. The harness will keep all that it learns in the world of this release.

  1. It puts agent attention first.It gives the attention of the agent to the parts of a task that need it.
  2. It breaks each task into small parts.System One models do this step. A System One model is a decision model. It gives typed answers with probabilities in 1 pass, without generating text.
  3. It learns your domain as you use it.Each thing that it learns becomes a fact or a function in the world, instead of a line in a chat or a prompt.

the approach

Frontier answers become AI intuition

The harness will turn each problem that a frontier model solves into AI intuition. A small local model then gives the same answer fast, at low cost, each time.

  1. A frontier model solves a problem 1 time.The harness keeps the solution as facts and functions in the world.
  2. A small local model learns the answer.The small model is a System One model. TypeSafe named this class of decision model after the fast System 1 of Kahneman [1] [2]. The Clef models of Cloudflare answer in the same request shape [3]. Clairic, also from Cloudflare, is a System One model that extracts fields from text [4].
  3. The next time, the small model answers.The frontier model works only on the parts that are new.

What you get

Each gain comes from 1 part of the harness.

What you getHow the harness gives it
You get back into the flow of programming.The harness does the small parts. You stay on the code.
You understand what each model does, and why.Each step and its cause are facts in the world. You can read each fact and correct it.
You pay for fewer tokens.A solved problem becomes reusable scaffolding: types and functions in the world. No model solves it again.
Lower-cost and local models can do the work.Each part of a task is small. A small model can do a small part.
